# 余香 · Afterglow

一个用 SwiftUI + SwiftData 打造的美妆 / 护肤品收纳 App：收纳你拥有的每一件，记录使用次数、剩余量和保质期。


## 版本
大改动升主版本（v1.0 → v2.0），小改动升次版本（v2.0 → v2.1）。版本号写在 `project.yml` 的 `MARKETING_VERSION`，测试版 IPA 的 Release 名称会自动带上它。
- **v1.0**：改名「余香 · Afterglow」，实物抠图站在玻璃架上
- **v2.0**：玻璃卡片与藏品总值、详情页成为唯一的使用页、第四个标签「我的」与统一背景墙
- **v2.1**（当前）：数据备份与恢复、隐私政策、首页逐件记、统一光源与圆角、空瓶纸感分享卡（用后感 + 复购印章）、空瓶时间线；修复启动闪退

## 功能
- **首次打开**：瓶子缓缓注满，"把梳妆台搬进手机"；「添加第一件」或「先看看示例」（示例可在设置里一键清除）
- **藏品**：顶部一张玻璃总览（藏品总值 / 件数 / 品牌 / 该先处理 / 备用）；按品类分层，每层横向滑动、放不下才滚，"该先用掉"（快到期 / 已过期 / 快用完）永远在最上层；分类胶囊带件数，备用库存显示 ×2；搜索名称或品牌
- **容器家族**：瓶 / 罐 / 管 / 面膜袋（显示剩余片数）/ 口红 / 粉盒，液面高度 = 剩余量，液面轻轻晃动（减弱动态效果时静止）；**抠图本身就是贴纸**——有抠图就直接显示它，没有抠图才画容器（有照片则把照片当圆形标签贴在瓶身上）
- **三种计量**：容量（ml / g，每次扣减用量）、按片计数（剩 7 / 共 10 片）、估算剩余 %（口红、眼影盘，在详情里直接拖动液面）
- **长按快捷菜单**：用了一次 / 编辑 / 用完了 / 删除
- **详情（唯一的「使用页」）**：首页、藏品、空瓶、近期记录点任何一件产品都打开它，产品图带着放大转场飞进来；大按钮「用了一次」（数字滚动 +1、剩余量和 14 天圆点即时更新、触感、短暂变成「已记下」并可撤销，不自动关闭）、开封 / PAO / EXP / 实际过期日、价格与每次成本；早间 / 晚间 / 化妆胶囊默认选中当前时段，记一次就带上这个时段；一起记多件时也进这一页，几件产品左右滑动逐件记，其中某件点「用完了」（或刚好用到见底）就收进空瓶墙并自动滑到下一件还没用完的，不退出，这一组都用完了才停下；最下面一排的「完成」也接着记下一件（这一组最后一件才退出）
- **保质期**：包装到期日（EXP）与 开封日 + 开封后保质期（PAO）取更早的那个；没开封的第一次使用时自动记为今天开封
- **使用手记（首页）**：一张玻璃卡只问一件事——「这次用了哪些产品？」，**不预选上次那件**：点「挑产品，逐件记」进挑选页，产品以玻璃卡片网格排开（实物站在一小段玻璃架上、选中的带描边和产品色，列数自适应 / 大字号自动变少列），勾几件后进详情页**一件一件地记**（某一件用完了会自动滑到下一件，不退出）；卡片右边那三只是「你的东西」的缩影，谁都没被选中。下面是「近期记录」（点任意一条打开那件产品的详情接着再记）和「连续 N 天 + 最近七天点阵」，今天还没记不清零，只鼓励不惩罚
- **今日（小仪式）**：当前时段（15:00 前早间，之后晚间）的产品按顺序排成一排"托盘"大卡片（有抠图显示实物，否则显示容器）；点「拿起来用」或把卡片往上推 = 记一次使用，卡片滑进下方"已用"一摞（轻点可撤销），伴随触感；顶部进度环；全部用完时环合拢，出现"晚间护肤完成，晚安"。「调整」里挑选产品、拖动排序（顺序按产品 uid 存在 App Group，小组件同序）。右上角可切换紧凑清单（大字号时默认清单）
- **小组件**：「今晚该用」（小 / 中）显示当前流程和进度，直接在桌面勾选（AppIntent，已勾再点撤销）；「快过期」（小 / 中 + 锁屏长条 / 圆形）显示最快过期的几件和剩余天数，按状态着色。午夜、15:00 自动刷新，App 内任何修改保存后也会刷新
- **空瓶记分享图**：空瓶页「生成空瓶记」→ 选按月 / 按年 → 生成 1080×1440 竖图，做成一版**近黑金句卡**：上方一大块空瓶陈列（暖光打在暗墙上、瓶子脚下化开自己的颜色），底部渐变压黑，白色无衬线金句左对齐贴底（"11 月空瓶，我用完了 4 件。它们一共陪了我 96 次，花掉 ¥1,281，平均每次 ¥3.4。"），下面几枚半透明胶囊（件数 / 次数 / 花费）、最底两个等宽圆角块（余香 Afterglow / 日期）→ 分享或存相册
- **空瓶**：玻璃统计卡（今年用空 / 用完的价值 / 平均每次 / 平均用多久）+ 待补货 + 空瓶墙（空的容器保留一道液体色残影、架板上一小片同色焦散，下面写用了几次、用了多久、每次多少钱；买到了 → 藏品多一件同款或备用库存 +1）；还没有空瓶时整页是一面空着的墙（三件磨砂的空瓶影子站在架板上）+「去藏品里挑一件」，不摆一张全是零的统计卡
- **空瓶时间线**：空瓶墙上方多一个「空瓶墙 / 时间线」分段切换（记住上次选的）。时间线按月分段、最近用完的在最上面，一条细竖线串起来，线上的点取产品自己的液体色；每个节点是一张小玻璃卡（实物小图、名称、品牌 · 用完日期、一条和这一批里最久那件相比的「陪伴时长」条、天数 · 次数 · 每次花费、复购态度小章），点开进详情，那里可以「分享空瓶」。没有开封日期的不画时长条，没价格不写每次
- **空瓶分享卡（每条记录一张）**：空瓶的详情页里「分享空瓶」→ 拿这一条记录直接排一张 1080×1440 的纸感竖图（`Services/EmptyShareCard.swift`）：暖米白的纸、墨黑的字，页眉「空瓶手记」+ 个人空瓶序号 `NO. 018`，一句按包装形式选量词的标题（这一瓶 / 这一支 / 这一罐 / 这一片 / 这一盒，看不出来就是「又用完了一件。」），主图是这条记录的实拍、没有就用产品的抠图、都没有就变成以产品名和心得为主的文字版；下面是产品名 + 原始规格（50 mL / 100 g / 10 片）、使用时长 / 用完日期 / 累计用量、以及自己写的用后感（长了在卡上节选，原记录不动）；复购态度是一枚朱红椭圆印章（会回购 / 再想想 / 不回购，没选就不盖）。心得和态度就在这张表里写回记录，切换记录跟着变；预览和导出用的是同一个视图 → 存相册或调起系统分享
- **我的**：身份卡（本机使用中 · 在用 / 空瓶 / 累计记下）+ 会员卡（云抠图、多设备同步、主题与小组件；标着「开发中」，现在全部免费，位置先留好）+ 日常流程 / 提醒与数据 / 关于；你也会在这里读到"数据只在这台手机上"
- **同一面背景墙**：今日 / 藏品 / 空瓶 / 我的四个标签页是**同一个冷瓷白**（`ScreenBackground()` 不带柔光），换标签不换气质；产品色的柔光只留在一处——详情页，让那一件自己的颜色透出来
- **一盏灯**：`Theme.Light` 是全 App 唯一的光源（左上来、暖白、影子往右下偏），架板 / 接触阴影 / 焦散光三个共用组件都从这里取值，所以每个屏幕的光一致
- **用完了**：容器倾斜倒空的动画 → 移入空瓶墙 → 询问是否加入补货清单（有备用库存时可直接开一瓶备用的）
- **15 秒添加**：拍照 / 相册（裁成方形）、名称、品牌、形状图块、容量快捷胶囊、每次用量 少量 / 适中 / 多、日期胶囊（开封、6M/12M/24M/36M、1/2/3 年后）+ 实时"会在 X 过期（按…算）"、折叠的「更多」（价格、备用库存、液体颜色、加入早间 / 晚间）
- **本地提醒**：到期前 30 天、7 天；剩余不到 15% 提醒补货；每晚 21:30 晚间流程提醒（可关）——在设置里开关
- **备份与恢复**：设置 → 数据 →「导出备份」把全部产品（含使用记录和照片）写成一个 JSON 文件，交给系统分享（存到「文件」/ iCloud Drive）；「从备份恢复」按 uid 去重，只补上还没有的，不覆盖现有数据
- **隐私**：数据只在这台手机上，没有账号、不上传；隐私政策见 `docs/privacy.html`（「我的 → 关于」有入口）；崩溃与卡顿只用系统 MetricKit 收在本机，可在设置里分享给开发者
- **无障碍**：减弱动态效果（托盘不做位移动画、液面静止）、动态字体、VoiceOver 标签（"剩 31 ml"）、可调节的估算液面、≥ 44pt 触控目标、深色模式

## 代码结构
```
BeautyShelf/
  App/        入口、RootView（欢迎页 / 标签页）、MainTabView、AppCoordinator
  Models/     Product（SwiftData）、SampleData
  Design/     Theme、容器几何（ContainerShapes）、ContainerView（晃动液面）
  Views/      Shelf（妆台、卡片、详情）、Today、Finished、Editor（表单、相机）、Welcome、Settings、Components
  Services/   NotificationService（本地通知）、ImageTools（方形裁切）、
              SharedStore（App Group 共享数据库 / 流程顺序 / 抠图缩略图）、
              ShareCard（空瓶记分享图）、EmptyShareCard（每条记录的空瓶分享卡）
Widgets/      小组件扩展 BeautyShelfWidgets：今晚该用（LogRoutineIntent）、快过期
Entitlements/ App 与小组件的 App Group 权限
```

数据：SwiftData 数据库放在 App Group `group.com.llmzhu.BeautyShelf` 里（`ModelConfiguration(groupContainer:)`），App 和小组件读写同一份。旧版本放在 App 沙盒里的数据库会在第一次启动时自动搬过去。App 里的修改经 `AppCoordinator.dataChanged()` 防抖保存并 `WidgetCenter.shared.reloadAllTimelines()`；小组件里勾选后，App 回到前台时会换一个新的 ModelContext 重新读取。

## 运行
需要 Xcode 15+ / iOS 17+（SwiftData）。

```bash
brew install xcodegen
xcodegen generate
open BeautyShelf.xcodeproj
```

**签名（小组件必需）**：在 Xcode 里给 `BeautyShelf` 和 `BeautyShelfWidgets` 两个 target 选同一个 Team，并在 Signing & Capabilities 里确认 **App Groups** 已勾选 `group.com.llmzhu.BeautyShelf`（权限文件已在 `Entitlements/`，个人账号需要在开发者后台或让 Xcode 自动注册这个 App Group；如果换了 bundle 前缀，同时改 `SharedStore.appGroup` 和两个 entitlements）。没开 App Group 时 App 仍能运行，但数据存在 App 自己的沙盒里，小组件读不到。
